# Project 12 — Mesin Vending Minuman (React.js)

Project mandiri untuk Soal No. 12:
- Menggunakan class `VendingMachine` (`src/models/VendingMachine.ts`).
- 3 jenis minuman tersedia:
  1. Aqua — Rp 5.000
  2. Teh Botol — Rp 7.000
  3. Pocari Sweat — Rp 10.000
- Menerima pecahan uang: Rp 2.000, Rp 5.000, Rp 10.000, Rp 20.000.
- Mendeteksi stok minuman yang sedang habis secara otomatis.

## Menjalankan secara terpisah
```bash
cd project-12-vending-machine
npm install
npm run dev
```
